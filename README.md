# Учебный портал Академии

Статический сайт с курсами трёх институтов: Институт управления, Институт дипломатии, Национальная школа госполитики.
В каждой теме 2–3 учебные страницы и тест; отметки о прохождении сохраняются в браузере (localStorage).

Открыть локально: просто откройте `index.html` в браузере.
Сайт: https://shynarqurmangali-sys.github.io/academy-courses/
