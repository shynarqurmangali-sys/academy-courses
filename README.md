# Учебный портал Академии · Оқу порталы · Learning Portal

Статический сайт курсов институтов Академии государственного управления при Президенте РК. Интерфейс и материалы на трёх языках: қазақша, русский, English.

- Курсы трёх институтов, включая «ЖИ этикасы және цифрлық тәуекелдер» и «Халықаралық цифрлық көшбасшылық және GovTech».
- В каждой теме 2–3 учебные страницы, тест с проверкой и заметки; итоговый экзамен с таймером и сертификат по курсу.
- Интерактивные модули: глоссарий-карточки, матрица рисков, политический цикл, уровень риска ИИ (EU AI Act), самооценка зрелости GovTech.
- Прогресс хранится в браузере (localStorage).

Файлы: `index.html`, `styles.css`, `app.js`, `i18n.js` (тексты интерфейса), `data/kk.js`, `data/ru.js`, `data/en.js` (учебные материалы), `assets/`.

Сайт: https://shynarqurmangali-sys.github.io/academy-courses/
